# Project charter — initial foundation

Owner: Jamie Haas. Authoritative brief: the original implementation plan at the root.

Build a local code-first mechanical design environment. First commission a
known-dimension CAD fixture. Then prepare a manually operated, bearing-supported
finger-joint demonstrator with removable cover and named shaft/magnet/PCB interfaces.
The eventual first release requires physical assembly and recorded observations.

Current scope: Phases 0–2 foundation. No mechanism load rating or completed
prototype is claimed. Phase 0 input collection and desktop commissioning remain open.
