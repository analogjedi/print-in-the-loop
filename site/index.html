Geared string winch for the BLDC stand

A 9:1 two-stage spur train (26→78, 23→69) from a gear on the motor's rotor to a string drum. It lifts a hanging weight 203.2 mm in 0.92 of an output turn, so a single-turn encoder on the output reads the weight's position absolutely. Press Run winch, drag the Lift slider, or use the cutaway.
