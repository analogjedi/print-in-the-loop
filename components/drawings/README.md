# Component information checklist

For each shaft, bearing, fastener, magnet, and sensor PCB, obtain the exact supplier
part number, drawing URL/file and revision, nominal dimensions with units, tolerances,
and confidence/provenance. Record dimensions in the component registry before modeling.

For the sensor pair, include allowed magnet alignment, axial gap, runout, PCB envelope,
mounting features, connector/wire access, and the source of each requirement.
No component drawings have been supplied yet.
